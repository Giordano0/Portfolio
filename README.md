# Personal Portfolio — Giordano Dolenz

A personal portfolio website built from scratch with HTML CSS and JavaScript, showcasing my projects and skills as a student of Applied Informatics & Data Analytics.

🔗 **Live site:** [giordano0.github.io](https://giordano0.github.io/Portfolio/)

---

## Features

- Animated floating background
- Sticky navigation bar with smooth scroll
- Hero section with latest project preview
- Tabbed projects section (Web, Python, C)
- Scroll-triggered fade-in animations
- Responsive layout for mobile and desktop
- Custom scrollbar styling

## Tech Stack

- HTML5
- CSS3 (Flexbox, CSS Variables, Animations, Media Queries)
- Vanilla JavaScript (IntersectionObserver, tab switcher)

## Getting Started

No dependencies or build steps needed. Just clone the repo and open `index.html` in your browser:

```bash
git clone https://github.com/Giordano0/Giordano0.github.io
```

Then open `index.html` directly, or use a local server:

```bash
# With Python
python -m http.server 8000
```
